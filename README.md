# Password Manager

Password Manager
A secure JavaFX-based password manager with AES-256/GCM encryption, user authentication, secure notes, and auto-lock functionality.

# Recommended Method
Clone the repository using the link below:
https://github.com/sinlincheng555/Password-Manager.git
Steps:

Open IntelliJ IDEA
On the main menu (welcome screen), click "Get from VCS" / "Clone Repository" in the top right
Paste the GitHub link above into the URL field and click Clone
Once the project opens, navigate to src/Main.java
Run Main.java directly — this is the entry point for the application


Note: If any code is highlighted in red, this indicates unresolved dependencies or 
configuration issues in the IDE. You can still run Main.java without any problem — 
the red highlights are cosmetic warnings and do not prevent the program from 
executing.
